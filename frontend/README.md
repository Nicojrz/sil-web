# Frontend del copiloto SIL

Este frontend ahora consulta el backend en http://127.0.0.1:8000.

## Probarlo

1. Levanta el backend:
   - cd backend
   - py -3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --app-dir c:\Users\axeln\Desktop\sil\backend

2. Abre el archivo index.html en un navegador o sirve la carpeta frontend con un servidor estático.
